# Hollow Hours — Static Edition

A lightweight recreation of the Quiet Kindness Corner page.

## Files
- `index.html` — page structure
- `style.css` — responsive visual design
- `script.js` — character counter, local anonymous notes, reveal animations, and generated ambient noise

## Deploy
This is a plain static website. GitHub Pages can serve it directly from the repository root.

No React, Vite, Bun, Node, or build step is required.

The anonymous thought feature stores entries only in the visitor's own browser (`localStorage`); it is not a public database.
